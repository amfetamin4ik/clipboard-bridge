# Мост — буфер обмена между устройствами

Статический сайт для GitHub Pages. Создайте мост, откройте ссылку на втором устройстве, нажмите «Подключиться к мосту». Вставьте текст и отправьте; на другой странице нажмите «Скопировать». Поддерживается двусторонний обмен между двумя открытыми вкладками.

Текст передаётся через WebRTC DataChannel. PeerJS Cloud используется для сигнализации. TURN-сервер не настроен: некоторые корпоративные, мобильные сети и VPN могут блокировать прямое соединение. Доставка подтверждается вторым устройством. Хранения сообщений и фонового доступа к буферу нет. Последнее полученное сообщение остаётся в памяти вкладки до очистки или перезагрузки.

Ссылка содержит случайный идентификатор комнаты и секрет доступа в URL-фрагменте. Любой обладатель ссылки может подключиться, пока мост открыт; делитесь ею только с доверенным устройством. Для новой сессии используйте «Новый мост».

## Публикация

Settings → Pages → Deploy from a branch → main → / (root).

## Локальная проверка

Запустите любой статический HTTP-сервер в этой папке. Clipboard API работает в HTTPS или localhost. Зависимость PeerJS 1.5.5 включена в vendor, лицензия MIT — рядом.
